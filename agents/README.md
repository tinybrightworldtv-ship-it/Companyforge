# CompanyForge Agent Framework

The agent framework defines how CompanyForge creates, identifies, permissions, coordinates, and audits AI agents.

## Core components

1. Agent Registry — authoritative list of available agents.
2. Agent Contract — common interface and safety boundary.
3. Permission Model — least-privilege tool and action access.
4. Task Model — structured work handed to agents.
5. Orchestrator — assigns work, tracks dependencies, handles escalation.
6. Audit Model — records consequential agent actions.

## Initial workforce

- CEO / Orchestrator
- Research
- Strategy
- Product Manager
- Builder
- QA / Critic
- Growth
- Customer Intelligence
- Operations
- Analytics
- Finance / Revenue
- Security & Governance

No agent is considered operational merely because it is registered. An agent becomes operational only after its tools, execution path, tests, and safety controls are implemented.
