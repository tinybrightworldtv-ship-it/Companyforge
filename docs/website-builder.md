# CompanyForge Website Builder

CompanyForge converts a company brief into an implementation-ready website specification.

Pipeline: company brief → website spec → brand/asset generation → Builder implementation → preview → QA/Critic → approval → deployment → analytics.

The asset plan supports original logos, hero imagery, illustrations, 3D scenes and 3D models. Assets remain planned/generating/ready until a provider returns evidence.

3D is contextual: no 3D, subtle motion, interactive scenes or product models may be selected. Noncritical 3D must be lazy-loaded and must not block core content.

Completion requires build/test evidence, responsive verification, accessibility checks and a real preview/deployment result.

Provider credentials remain server-side; generated websites receive only explicitly approved integration credentials.
